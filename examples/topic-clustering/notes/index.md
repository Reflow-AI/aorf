# Notes

Loose notes, captured as they come up. A note is a thought worth not losing — an idea, an
observation, something read somewhere, a doubt about a decision already made. It is not a
decision, a question or a plan, and nothing in the research derives from it.

Notes exist so that a thought can be recorded without paying the cost of structuring it. The
moment an idea has to be turned into a question or an experiment before it can be written down,
it does not get written down.

## This directory is not part of the AORF structure

Despite the filename, this `index.md` is **not** an AORF document, and neither is any note. No
`type`, no `research_status`; nothing here is validated, rolled up or counted. `notes/` is a
payload directory — see section 1 of `AGENTS.md`.

## One note per file

`notes/YYYY-MM-DD-short-slug.md`. The date is the day the note was taken, so the directory
listing sorts chronologically on its own.

There is deliberately no maintained list of notes in this file. A hand-updated index goes stale
and becomes the thing nobody wants to maintain, which is the problem one-note-per-file exists to
avoid. The directory listing is the index; the `brief` in each note's frontmatter is the summary.

## Reviewing

Notes are for reviewing later, not for acting on now. A review pass reads the briefs, and each
note either becomes something in the research proper (`status: promoted`), gets rejected with a
reason (`status: dropped`), or stays `open` because it is still not the right time.

Nothing is deleted. A rejected note is cheaper to keep than to re-derive.
